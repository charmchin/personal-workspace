## 任务如何删除

此前 Rust 命令已经支持删除任务，但日程页面缺少对应操作，属于前端功能遗漏。

现在可在「日程 → 任务清单」点击每条任务右侧垃圾桶，或点击任务打开编辑窗口后选择「删除任务」。已完成任务可通过全局搜索定位到编辑窗口再删除。尚未保存的新任务只需取消，不显示删除入口。

删除前须确认；取消不修改数据库。提交期间禁止重复删除、编辑和保存；失败提示保留在编辑窗口内并保留草稿。成功后任务清单与日历同步更新，其他任务不受影响。重复任务会从未来显示中移除，但已经独立生成的其他任务记录不连带删除。

普通删除不会自动清除历史快照中的那条记录；「删除一条任务」与本次「清除所有旧库及旧快照」是不同范围。不要将普通删除描述为安全擦除。
