## 结论与执行范围

本轮处理了已确认的业务计算、日程时间、交互、快照和多进程问题，并继续沿用前轮恢复中断、会话撤销、备份验证及行情取消保障。没有整体重写，也没有把测试通过称作绝对安全。

只修改工程与生成本地构建产物；所有数据库、恢复、删除、错误注入和性能测试使用临时合成数据，网络测试使用回环服务与虚构凭据。没有读取个人业务数据库或真实钥匙串内容，没有替换 `/Applications/个人工作台.app`，没有推送 GitHub、发布或进行 Developer ID 签名/公证。已安装版不自动获得本轮修复。

## 本轮修复

### 1. 多进程与依赖

- 新增数据目录生命周期文件锁，在锁定界面、迁移与恢复期间仍持有。第二个合作进程不能打开同一工作台，尝试聚焦已有窗口后退出。拒绝锁路径符号链接、非普通文件与硬链接，打开后核对文件身份。
- 退出后保留 `instance.lock` 空文件，操作系统释放锁；运行时不可删除或替换它。旧安装版没有该协议，仍不可与新副本同时运行。
- 初始化、钥匙串解锁、口令解锁及改口令共享后端即时认证互斥，避免并发认证竞争密钥文件；前端连续 Enter 也不再重复提交。首次初始化已留下口令包装文件但尚无数据库时，禁止重新生成覆盖密钥，可用原口令继续初始化并重新打开。
- 锁文件使用 Rust 标准库文件锁，声明 Rust ≥1.89；本轮以 1.98 验证，不宣称最低版本已全流程测试。
- rustls 锁定版本由 0.23.43 升至 0.23.45；Vitest 升至 4.1.11。重新生成并离线校验 517 项第三方依赖声明。npm 审计当前无已知漏洞，未将此等同于全依赖安全认证。

### 2. 日程与日期

- 定时事件、任务安排与内容发布时间规范化为 UTC；前端编辑/显示显式使用上海时区，不再截取 UTC 字符串当本地时间。旧的无时区日期时间按上海时间理解。
- 全天事件保持上海日期与结束日期不包含当天的边界，跨午夜与跨日重复在相关日期均可见；首页下一项日程保留重复事件持续时间，并处理尚未结束与下一次发生。
- 默认日期、日期切换、习惯、工作周统计和内容周复盘显式采用上海日期。系统时区变化不会把上海午夜附近内容算到前一天。
- ICS 保留来源/UID 去重更新；支持浮动上海时间、Asia/Shanghai 与 UTC/Etc/UTC。简单每日/每周/每月重复支持间隔 1；复杂规则、异常结束边界、其他 TZID 和缺失 UID 明确跳过并提示，不静默变成无限重复。
- 导出标准 UTC 文本、保留 UID、按 UTF-8 字节折行；修正反斜杠/换行转义。导入导出按钮操作没有接反，实际修复的是时间与文件内容边界。导出仍包含已导入事件，不是只导出内部来源。

### 3. 投资计算与展示

- 无价格的非零持仓标记为未知，不能显示为已亏损全部成本；组合明确展示“已知市值小计”，不把不完整估值当完整总资产。
- 分红扣除费用和税费；买卖/申购/赎回拒绝零份额；现金资金调整支持正负金额并拒绝负余额，资金调整不混入费用/税费。
- 手工价格形成当日上海日期价格点，同日优先于行情；较早行情不覆盖较新价格。清空手工输入不等于删除历史价格，界面提示保留历史记录。
- 金融 JSON 数字保留原始十进制文本；金额格式化使用十进制字符串与 BigInt，避免超过 JavaScript 安全整数后显示错金额。
- 交易重算加入稳定 ID 排序；全部卖出时分摊完整剩余成本，消除有限精度平均成本带来的残留收益偏差。价格与交易失败仍通过前轮保存点回滚。
- CSV 导入先明确选择账户；交易支持确认删除，删除后校验完整序列；估值异常不会阻塞账户、资产和交易编辑，允许纠正坏数据。

### 4. 交互与布局

- 共享弹窗使用原生 dialog 顶层显示；错误位于当前弹窗内并接收焦点。保存期间阻止重复提交、关闭、Escape 与背景点击；失败后保留表单、恢复可编辑状态。
- 已关闭弹窗不挂载内容，避免隐藏错误、重复元素及表单内容长期残留；设置与口令操作增加即时提交互斥。
- 文件选择窗口的错误被捕获并显示在当前页面/弹窗，不再形成未处理拒绝；ICS 导入展示首个跳过原因。后台加载成功不会清掉刚发生的日程操作错误。
- 全局搜索加入日程、习惯与证券代码，SQL 通配符按字面匹配；选择结果直接定位/编辑对应记录，而非只进入模块首页，过期搜索响应不会覆盖新搜索。
- 日/周日程不再截断事件；月历超额项可跳到完整日视图。事件与日期使用独立可聚焦按钮，避免嵌套按钮。
- 工作日志、交易、任务清单分批呈现；切换页面重置主内容滚动位置。自媒体“完成复盘并归档”明确状态含义。
- 后端 SQL 错误只返回受控说明，不回显可能含密钥、参数或私人值的 SQL 文本；密钥十六进制与携带密钥的临时 SQL 字符串使用释放时清零容器。此措施不保证清除 SQLite、系统或 WebView 的全部内部副本。

### 5. 自动最近恢复点

- 日快照保留 7 个、周快照保留 4 个；增加独立保留 3 个的 `latest-*` 最近恢复点。
- 解锁期间监视数据库变化，约每 5 分钟更新一次；日期跨日不受同日节流阻挡。正常退出尝试补一次；锁定、繁忙或强制退出时不能保证捕获最后写入。
- 写入随机临时文件，完整性检查与文件同步后原子改名，并同步父目录；正常失败自动清理临时文件，不留下半成品作为可恢复快照。
- 快照失败显示警告、节流重试，不撤销已成功保存的业务记录。设置页定期刷新列表，新增恢复点可见、可恢复、可确认删除。
- 快照监视与原生会话撤销分离，避免慢快照阻塞授权撤销。没有安装独立后台服务，监视线程仅随应用运行。

这仍不是实时备份：数据库本身使用 WAL 与完整同步；磁盘损坏或丢失时，同机快照也会受影响。需要定期导出独立密码备份至可靠介质。突然终止可能留下加密临时文件；中断恢复诊断文件不会自动当垃圾删除。

## 尚未完成或不能承诺的部分

1. 锁定状态下的独立密码备份灾难恢复入口仍未实现；不能承诺遗忘口令后可以恢复。遗忘当前口令时不要删除库或密钥包装文件。
2. 不支持完整复杂 ICS、全 IANA 时区、Apple 日历同步、自动交易/发布或云同步。当前金额是有限精度十进制，除法有精度边界，不是任意精度金融引擎。
3. 收益图与周复盘不能视为历史组合净值回放或正式投资业绩计算；跨模块关联编辑、复盘历史投资变化等尚未全部实现原始规划。
4. 大数据 UI 已分批渲染，但部分 SQL/API 仍全量读取；没有把 10,000 条任务的本机性能结果外推到无限数据量或每种低端设备。
5. 不提供完全清零系统内存、绝对无痕卸载或防御本机系统级恶意程序的承诺。事件通知依赖 macOS，真实锁屏/唤醒、系统认证、最低系统/工具链与最终 WebView 交互仍需实机验收。
6. 本轮已知依赖安全修复不等于所有 Rust 上游维护风险消失；`unic-*` 等上游维护问题需继续跟踪。正式开源提交、版本发布、持续集成、安装升级和 Developer ID 签名/公证是后续独立步骤，本轮未执行对外操作。
