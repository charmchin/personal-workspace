# 0.1.5：今日行动与跨模块关联

## 使用逻辑

任务表示需要完成的行动，工作记录表示结果、问题、下一步和实际耗时，两者不是同一类数据。写日志不会自动生成任务。

例如从一条工作日志安排下一步：在工作记录卡片点击“创建待办任务”，确认标题、截止日期、优先级和需要的关联，再“保存任务”。日志保留，新任务与日志同时建立关联；取消不写入任务。已经关联时按钮变为“查看关联任务”，不会重复创建。

任务可以同时关联一个项目、一个成长目标和一条自媒体内容；一条日志可关联一个任务，多条日志可以关联同一任务。在自媒体或成长模块，打开已保存内容／目标，底部的“关联任务”区提供查看与创建入口；新建的内容／目标需先保存再关联。

| 模块 | 保存或完成后的影响 |
| --- | --- |
| 今日／日程任务 | 更新同一张任务表；完成后计入相应完成日期的周复盘 |
| 工作记录 | 记录实际结果与耗时；创建待办是明确确认的独立操作 |
| 自媒体 | 内容阶段和指标独立保存；关联任务完成不等于已发布 |
| 成长目标 | 目标进度由用户确认；关联任务完成不自动更改百分比 |
| 习惯 | 当日打卡参与习惯汇总，不创建任务或工作日志 |
| 投资 | 独立交易与价格模型，不由任务完成触发交易 |

关联不是状态联动。删除任务解除日志关联，不删除日志；删除目标／内容会通过外键解除任务对应关联。附件仍为原文件路径引用，不随任务复制或删除。

## 今日重点与优先级

今日待办包含未完成的到期、逾期、没有截止日期，或计划在上海时区今天开始的任务。明确设为未来日期且不满足上述条件的任务留在日程清单；工作记录不直接进入今日重点。

今日预览最多显示 5 条待办和 3 条今日已完成，完整数量单独统计，并提供查看全部入口。最前面的 3 条有编号，用于突出优先行动，不代表其余任务不存在。待办按优先级、截止日期、同条件下进行中优先排列；完成预览按完成时间倒序。

- P1＝重要，P2＝正常（默认），P3＝稍后。行内显示中文，悬停或编辑时可见代码对照。
- 点击标题＝打开编辑；勾选复选框＝完成；取消勾选＝恢复待办。
- 已完成条目有勾选、删除线和“已完成”提示；日程可筛选已完成／全部并删除。
- 重复任务从复选框完成后，保留本次历史并推进下一次。历史日志关联已完成的本次，避免日志跟随下一次任务。
- 工作记录默认实际耗时 0，需手动填写；旧记录的耗时不批量改写。
