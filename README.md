个人工作台是一款单用户桌面应用，以「今日」为行动入口，将日程、自媒体、投资、成长、工作记录与周复盘连接起来。它面向希望持续记录和整理个人事务，又不想把这些数据交给云服务的使用者。

无需注册账号；业务功能默认离线运行；没有云同步、遥测或广告。可选行情由用户主动启用，不是使用其他模块的前提。

> 当前源码版本为 **0.1.5，早期预览**。本版本修复今日任务交互与统计，并补齐工作日志、自媒体、成长目标的行动关联，见[更新日志](CHANGELOG.md)。请先用非关键数据体验，定期导出加密备份；详见[已知限制](#已知限制与改进方向)。源码版本不表示每台设备已安装该版本。

[v0.1.5 预发布](https://github.com/charmchin/personal-workspace/releases/tag/v0.1.5) 已公开，发布说明包含功能、升级注意、验证证据及已知边界。该版本**仅提供源码，不提供安装包**；Release 页面自动生成的 `Source code (zip)` / `Source code (tar.gz)` 不是可直接安装的 `.app` 或 `.dmg`。

首次体验请按下方步骤获取固定的 `v0.1.5` 标签并在本机构建。`main` 是持续开发分支，后续文档或代码可能与该发布版本不同；发布标签不随 `main` 更新，也不自动升级本机应用。当前尚无 Apple Developer ID 签名、公证或稳定版承诺。

## 为什么做这个工作台

- **以行动为中心。** 首页呈现任务、日程、习惯和待推进内容，记录后能继续安排下一步。
- **让记录形成闭环。** 计划、执行、日志与复盘共享同一套本地数据，而不是各自成为孤立清单。
- **数据由自己保管。** 使用加密本地数据库和独立密码备份，不依赖云端账号或订阅服务。
- **保持明确的边界。** 不连接券商、不代发内容、不扫描本机目录，也不将投资记录包装成投资建议。

界面采用暖灰与深墨绿配色、系统字体和 Lucide 图标，支持浅色、深色与跟随系统模式。目标是适合每天打开的桌面工具，而不是信息堆叠的大屏。

## 功能概览

| 模块 | 当前提供的能力 |
| --- | --- |
| 今日 | 重点任务、下一项日程、习惯进度、内容推进、工作记录与投资摘要；快速捕获 |
| 日程 | 任务、事件、时间块；日 / 周 / 月视图；基础每日、每周、每月重复；项目／目标／内容关联；已完成任务筛选；ICS 导入与导出 |

| 工作记录 | 项目日志；完成、问题、下一步、实际耗时和精力状态；Markdown 文本与本机附件引用；明确创建或关联待办任务 |
| 复盘 | 按周生成数据摘要；编辑个人判断；保存草稿或确认复盘 |

自媒体的基础流程为：

```text
灵感 → 待策划 → 制作中 → 待发布 → 已发布 → 待复盘 → 已归档
```

`⌘K` 打开全局搜索与命令面板，支持定位并打开具体记录。今日任务标题用于编辑，复选框用于完成；已完成任务带删除线。工作记录不会自动变成待办，可明确“创建待办任务”；已保存内容与成长目标也可创建关联任务。关联不自动更改发布阶段或目标进度，详见[模块联系与验收](docs/0.1.5-行动关联与验收.md)。

首版面向单人使用，默认简体中文、上海时区和人民币；多语言、多时区和其他平台尚不属于已验收能力。

## 快速开始

### 1. 准备环境

- Apple Silicon Mac。应用配置的最低系统版本为 macOS 11，但不代表已逐一验证所有系统版本。
- Node.js：推荐使用满足依赖要求的 LTS 版本；当前 Vite 锁定版本要求 `^20.19.0 || >=22.12.0`。
- Rust stable 与 Cargo，Rust 至少 1.89（使用标准库文件锁）；本轮实际以 1.98 验证，不等于完整最低工具链兼容性验收。
- Xcode Command Line Tools，或已完成初始化的 Xcode。

仅开发桌面应用时，可以使用 Command Line Tools；安装步骤见 [Tauri 官方环境指南](https://v2.tauri.app/start/prerequisites/#macos)。

### 2. 获取源码并启动

获取与发布说明一致的固定版本：

```bash
git clone --branch v0.1.5 --depth 1 https://github.com/charmchin/personal-workspace.git
cd personal-workspace
npm ci
npm run tauri dev
```

该方式检出发布标签，Git 提示 `detached HEAD` 是正常现象，不妨碍构建。若要贡献代码或获取未发布改动，请改为克隆 `main`，再按[贡献指南](CONTRIBUTING.md#环境与分支)创建工作分支；不要在未保存改动的目录中直接切换版本。

首次构建需要下载 npm / Cargo 依赖，并编译 Rust、SQLCipher 与其加密依赖，耗时取决于网络和设备。**业务离线运行不等于首次安装依赖也无需联网。**

`npm run tauri dev` 会启动完整桌面应用以及 Vite 开发服务器。单独执行 `npm run dev` 只有界面开发服务，不能替代带数据库和安全能力的桌面应用。

### 3. 初始化自己的工作台

1. 打开应用，选择「安全初始化并解锁」。
2. 按当前构建的提示使用 macOS 钥匙串，或设置独立工作台口令。
3. 创建一项任务或一条工作记录，体验「今日 → 执行 → 记录 → 复盘」。
4. 在「设置 → 备份与恢复」导出一份加密备份，并妥善保存备份密码。

工作台口令与 Mac 登录密码、手动备份密码是不同概念。口令模式支持验证旧口令后更换口令，成功后需要重新解锁；最低 6 个字符只是便利性下限，建议使用更长的独立口令。

> 开发版与安装版默认使用相同应用标识和数据目录。新源码用文件锁排斥第二个合作进程，但旧安装版没有该协议，仍不要同时运行新旧副本；不要用真实数据库进行恢复、迁移或破坏性测试。

## 构建与安装

在项目根目录执行：

```bash
npm run app:build
```

生成的应用位于：

```text
src-tauri/target/privacy-build/aarch64-apple-darwin/release/bundle/macos/个人工作台.app
```

该入口固定构建 arm64 `.app`，自动配置 Rust / 原生编译路径脱敏，检查 OpenSSL 生成元数据，并在本地 ad-hoc 资源签名后扫描二进制和资源；不等同于 Developer ID 签名或公证。直接调用 `tauri build` 缺少参数时会被预检拒绝；开发入口 `npm run tauri dev` 不变。构建缓存独立保存，不覆盖旧构建目录，也不自动安装应用。细节及边界见[构建隐私说明](docs/构建隐私与产物检查.md)。

退出旧版并确认新构建适用后，可使用 Finder 将产物复制到「应用程序」，再从启动台、Finder 或终端打开：

```bash
open "/Applications/个人工作台.app"
```

安装后的应用运行不需要 Node.js、Rust 或 Vite 开发服务器，也没有另行安装的数据库服务。macOS 使用系统 WebView 渲染界面；生产版不会启动本地 HTTP 服务、后台常驻服务或自动更新器。

当前以源码构建为主要使用方式。本机构建、临时签名与 Apple Developer ID 签名 / 公证不是同一回事；不要将自建 `.app` 视为已经公证的公开发行包。面向其他用户分发时，仍需完成签名、公证和发行验收。

## 数据与安全

### 数据保存在哪里

已保存的业务记录写入本机 SQLCipher 数据库，正常关闭和重新打开应用不会主动清空记录。默认数据目录为：

```text
~/Library/Application Support/com.local.personalworkbench/
├── workbench.sqlite3        加密业务数据库
├── database-key.age         口令模式下的加密密钥包装文件
├── instance.lock            新源码的跨进程实例锁（退出后保留空文件）
└── backups/                 日 / 周 / 最近快照及操作前恢复点
```

SQLite 运行时还可能生成 WAL / SHM 文件，部分安全模式会产生模式标记。不要在应用运行时手工修改数据库，也不要单独删除密钥文件。删除源码或 `.app` 不等于删除业务数据。

附件和素材仅保存用户选择后的路径引用，不复制进数据库，不扫描目录。**数据库备份不包含附件文件本身**；移动、删除原文件或换电脑后，需要另外维护这些文件。

### 当前实现的保护

- 数据库使用 SQLCipher 全库加密；启用外键、WAL、完整同步、事务迁移与忙等待。
- Rust 后端负责数据库、密钥、文件和网络操作；前端通过命令边界调用，不开放通用 SQL 或任意文件读写接口。
- 优先使用要求用户在场认证的 macOS 钥匙串保护随机数据库密钥；实际模式受签名与系统权限影响。不可用时会尝试登录钥匙串，再提示使用独立口令模式。
- 口令模式通过 age / scrypt 加密包装随机密钥，不将口令或裸密钥写入数据库。登录钥匙串回退模式不等同于每次都要求 Touch ID。
- 支持手动锁定、后端闲置期限检查与 macOS 原生通知。锁定撤销新访问，页面清理业务内容与口令输入；已经开始的写入安全收尾后关闭连接。
- 前端 CSP 限制脚本、连接和嵌入页面。Tushare Token 单独存入钥匙串，不纳入业务数据库或备份。

加密与锁定不能防御所有威胁：已解锁设备上的恶意程序、屏幕截取、系统级入侵及用户主动导出的数据，不在本项目能够完整控制的范围内。系统通知也不能保证所有 macOS 版本上零延迟或永不丢失。

### 快照不等于独立备份

- **自动快照：** 解锁时尝试创建当日 / 当周快照，已有同名快照不刷新，保留最近 7 个日快照和 4 个周快照。新增最近恢复点：解锁期间检查数据库变化，约每 5 分钟更新一次，独立保留 3 个；正常退出尝试补一次。失败显示警告并节流重试，不回滚已保存记录。这是尽力完成的快照，不是实时备份；强制结束、忙碌或锁定时不能保证补齐最后写入。
- **操作前恢复点：** 数据库升级、口令修改和恢复前创建，各类通常保留最近 5 个。
- **手动备份：** 导出为单一 `.workbench-backup` 文件，使用独立备份密码加密。建议另外保存在可靠介质，并定期验证恢复。
- **管理与恢复：** 设置页可以恢复或确认删除单个快照；恢复前保留当前库恢复点。删除快照不可撤销，中断恢复的诊断文件不按普通快照自动轮换。

恢复前校验包含密码与完整解密、`quick_check`、支持版本与必需结构、外键关联、设置及投资序列检查；手动备份格式 2 核对 17 张表的记录数。仍可读取有效的格式 1 旧备份，但旧备份只有总数，不能补出其历史逐表清单。手动备份密码最低 10 个字符，与最低 6 个字符的工作台口令独立。0.1.5 使用数据库结构 2，可验证并升级有效的结构 1 备份；更早应用不能直接打开结构 2，也未必支持备份格式 2。0.1.2 起加入恢复中断识别、原子替换与已验证旧库回滚，不将未知候选库自动提升为主库。

自动快照与数据库位于同一设备，不能替代防范磁盘损坏或设备丢失的独立备份。遗忘工作台口令没有后门；当前界面也尚未提供锁定状态下的独立备份灾难恢复入口。

### 可选联网行情

Tushare 默认关闭，不配置 Token 也能使用工作台。启用后，由 Rust 后端向 `https://api.tushare.pro` 查询行情；请求包含 Token 和证券查询参数，不上传账户、持仓份额、成本或收益。

行情请求固定到上述 HTTPS 地址，禁用自动重定向及代理，按实际读取量限制响应正文不超过 1 MiB；服务端原始错误正文不会直接回显。代理专用网络可能无法查询行情。

支持取消在途行情：关闭联网设置保存成功、后端会话撤销或开始恢复时，唤醒并丢弃正在等待的 HTTP 请求；恢复期间拒绝新刷新。同一应用进程只允许一个刷新批次，旧批次不能跨过关闭再开启联网、重新解锁或恢复后写入，价格与刷新时间事务提交。不能撤回已发出的请求，正在执行的系统认证和已开始提交的 SQLite 事务不被粗暴中断；代理专用网络、系统通知及 TLS 依赖仍有下述限制。

行情不可用时保留已有价格，并可使用手工录入；同日手工价格优先于行情，原价格历史保留。对联网有严格要求时，请保持行情关闭。

投资模块仅用于个人记录与分析，不提供投资建议，也不执行交易。金融数值有可表示范围与有限精度边界，不应直接用作交易、税务或其他财务决策依据。

## 技术架构

界面使用 React 19、TypeScript、Vite、Zod、Recharts、TanStack Table、date-fns 和 Lucide；桌面壳与业务后端使用 Tauri 2 / Rust。SQLCipher 随 Rust 构建集成，不要求用户安装独立数据库。

金融数值以十进制字符串跨命令边界传输，由 `rust_decimal` 计算；使用移动加权平均成本模型。精确十进制避免二进制浮点误差，但不意味着领域规则或溢出边界已经没有缺陷。

```text
src/
├── pages/                   今日、日程、自媒体、投资、成长、工作、复盘、设置
├── components/              桌面壳、命令面板与通用 UI
├── lib/                     命令调用、Zod 校验、格式化与前端会话同步
└── styles/                  主题、布局与页面样式
src-tauri/
├── capabilities/            主窗口能力配置
└── src/
    ├── commands.rs          Tauri 命令、ICS / CSV 与行情调度
    ├── quotes.rs            安全行情传输、取消/恢复隔离与批次提交
    ├── cancellation.rs      可唤醒取消信号，不依赖前端轮询
    ├── repository.rs        领域 CRUD、搜索、汇总与投资计算
    ├── database.rs          SQLCipher、钥匙保护、迁移与快照
    ├── backup.rs            加密备份与恢复
    ├── restore.rs           中断识别、候选校验与安全回滚
    ├── session.rs           闲置期限、访问撤销与认证会话代号
    └── native_lock.rs       macOS 通知监听与后端监视
```

## 已知限制与改进方向

综合修复已覆盖日期转换、简单 ICS 往返、投资边界、多账户 CSV、搜索定位、弹窗操作、最近恢复点及新进程间排他；0.1.5 进一步补齐任务关联与完成反馈。本机源码、安装及验收状态分别记录在[综合修复与验收](docs/2026-10-03-综合修复与验收.md)和[0.1.5 行动关联与验收](docs/0.1.5-行动关联与验收.md)，不应混同历史安装版与当前源码。仍有以下边界：

- **日程范围：** 支持一次性、每日、每周及每月简单重复；复杂 ICS 规则或不支持的 TZID 明确跳过并报告，不静默转换成无限重复。当前不提供完整 IANA 时区和复杂周期模型。
- **投资精度与复盘：** 使用有界精确十进制，不是任意精度引擎；不能精确表示的输入或溢出会被拒绝，除法仍有有限精度边界。收益曲线与周复盘不构成历史组合净值回放、资金加权/时间加权收益或投资建议。
- **恢复与锁定：** 尚无锁定状态下的独立备份灾难恢复入口；忘记口令没有后门。新源码进程使用同一数据目录的实例锁，但旧安装版不配合该协议，仍不可与新副本同时运行。通知送达不保证零延迟，不能撤回已发出的请求或强行中断已开始的提交。
- **规模与关联：** 长列表已分批呈现，但部分查询仍全量读取；更大数据集需继续做 SQL 分页和内存验收。任务已有项目／目标／内容关联、日志关联入口，但多任务日志、学习项目关联及周复盘历史投资变化等仍未覆盖完整原始规划。
- **发行准备：** 已升级本轮确认的 rustls / Vitest 安全修复并更新许可声明；此前本机 npm 审计为零已知漏洞，不代表实时无漏洞或所有 Rust 依赖已全面审计。CI 已配置，云端运行需以 Actions 实际记录为准；部分上游维护风险、稳定版本、Developer ID 签名、公证及全流程实机验收仍需独立完成。
